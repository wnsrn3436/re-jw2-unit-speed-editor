# CEI 이동속도 포맷

쥬라기원시전2 유닛의 이동속도는 CEI 파일에 방향별 구간으로 나뉘어 적혀 있다.

| 오프셋 | 방향 |
|---|---|
| `0x3CC` | 상 |
| `0x5CC` | 우상 |
| `0x7CC` | 우 |
| `0x9CC` | 우하 |
| `0xBCC` | 하 |
| `0xDCC` | 좌하 |
| `0xFCC` | 좌 |
| `0x11CC` | 좌상 |

각 구간은 `0x200` 바이트 크기다. 속도 구간이 끝나는 `0x13CC` 에서 12바이트 뒤인 `0x13D8` 에 프레임 개수가 4바이트로 적혀 있다.

이동속도는 4바이트로 쓰이며 {좌우속도, 상하속도}의 8바이트 쌍으로 되어 있다. 눈으로 구분하기 어렵다면 홀수 번째와 짝수 번째로 나눠 보면 쉽다.

CHR 파일의 `m#.spz` 이동 그림을 기준으로 이동속도가 적용되므로 8바이트마다 이동 그림 한 장의 속도를 뜻한다. 한 방향 구간이 `0x200` 바이트라서 이동 그림 64장까지만 속도를 넣을 수 있다.
